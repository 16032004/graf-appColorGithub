1.1 Descripción del Proyecto

El presente proyecto corresponde al Primer Seguimiento de la materia de Graficación, cuyo objetivo principal es desarrollar una aplicación web interactiva que permita al usuario visualizar y manipular colores mediante tres esquemas diferentes: controles RGB, entrada manual de valores decimales y un selector de color (color picker).
Este proyecto se centra en reforzar fundamentos esenciales de HTML5, CSS, JavaScript, así como la integración de Bootstrap para implementar una interfaz limpia, ordenada y funcional.

Durante el desarrollo, se siguieron instrucciones progresivas que permitieron:

  1. Configurar el entorno de trabajo mediante la instalación de Visual Studio Code y extensiones clave como Live Server, Material Icon Theme, Tokio Night, Activitus Bar y BlackBox.

  2. Crear la estructura de archivos dentro de las carpetas Graficacion / 1er seguimiento / graf-appColor, facilitando la organización adecuada del proyecto.

  3. Construir una plantilla HTML5 y visualizarla correctamente con Live Server.

  4. Desarrollar una aplicación con Bootstrap que muestra un recuadro de color y tres controles deslizantes para los valores RGB, junto con su representación en código hexadecimal.

  5. Modificar el programa para aceptar valores RGB ingresados manualmente y reflejarlos en el recuadro visual.

  6. Integrar un color picker que sincroniza su selección con los controles RGB y el cuadro de color.

  7. Estilizar la aplicación mediante un diseño moderno, limpio y agradable, aplicado con CSS y sugerencias generadas con apoyo de ChatGPT.

El resultado final es una herramienta didáctica que permite comprender de manera práctica:

  • Cómo se forman los colores en formato RGB.

  • Cómo convertirlos a hexadecimal.

  • Cómo estructurar una interfaz interactiva utilizando HTML + CSS + JS + Bootstrap.

  • Cómo trabajar con eventos, manipulación del DOM y sincronización de controles gráficos.

Este proyecto no sólo desarrolla habilidades técnicas, sino que también promueve el análisis, la organización del código y la capacidad de implementar mejoras visuales y funcionales basadas en instrucciones progresivas.
